# Chào mừng đến với TinaCMS! 🎉

Đây là bài viết đầu tiên được tạo và quản lý hoàn toàn bằng **TinaCMS** trên nền tảng **Next.js App Router**.

### Tính năng nổi bật:
- 🚀 **Git-backed**: Mọi nội dung lưu trực tiếp dưới dạng file Markdown / JSON trong repository.
- ✨ **Visual Editing**: Chỉnh sửa trực tiếp trên giao diện trực quan.
- 🔒 **Độc lập và bảo mật**: Hoạt động mượt mà cả ở Local lẫn Production.
